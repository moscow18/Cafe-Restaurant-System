## 🌟 المميزات الرئيسية

### 1. 🧾 كاشير ونقاط البيع السريعة (POS & Touchscreen Invoicing)
- **واجهة عصرية وفائقة السرعة:** مصممة خصيصاً لتناسب الشاشات اللمسية ومجهزة باختصارات لوحة المفاتيح الكاملة لتسريع عمليات البيع في ساعات الذروة.
- **تنوع أنماط الطلبات:**
  - **صالة (Dine-in):** ربط الفاتورة بالطاولة مع متابعة حساب الطاولة المفتوح.
  - **تيك أواي (Takeaway):** تسليم فوري مع كاش سريع.
  - **دليفري (Delivery):** إدارة بيانات العميل وعنوانه وتعيين الطيار وحساب رسوم التوصيل.
- **أزرار المهام السريعة:**
  - `[F2]` **كاش سريع:** حفظ وسداد فوري بضغطة زر واحدة.
  - `[F3]` **المطبخ والبار:** طباعة تذكرة تجهيز الأصناف دون محاسبة.
  - `[F4]` **الشيك:** طباعة ريسيت الحساب للمعاينة والدفع على الطاولة قبل إغلاق الفاتورة، مع الحفاظ على كامل تفاصيل الفاتورة الأصلية.
- **تفريغ تلقائي وسلس:** تصفير فوري وتلقائي لشاشة الفاتورة فور السداد دون أي تجميد (No Freeze Guarantee).
- **طرق دفع متعددة:** نقدي، فودافون كاش، إنستا باي، بطاقات بنكية (فيزا)، وحسابات الآجل للعملاء.

---

### 2. 📱 منيو الـ QR التفاعلي والطلب الذاتي (Self-Ordering QR Menu)
- **كود QR لكل طاولة:** مسح الكود من هاتف العميل يفتح منيو رقمي سريع وجذاب دون الحاجة لتحميل أي تطبيقات.
- **تتبع حي ولحظي (Real-time Live Tracker):**
  - متابعة حالة الطلب خطوة بخطوة: `في انتظار التأكيد` ⏳ ⬅️ `جاري التحضير في البار/المطبخ` ☕ ⬅️ `تم التقديم للطاولة` 🎉.
  - مزامنة سحابية مباشرة عبر **Supabase Realtime** و **Server-Sent Events (SSE)**.
- **تصفير وتفريغ ذكي وفوري:**
  - فور قيام الكاشير بمحاسبة الطاولة، يستقبل هاتف الزبون إشعار السداد ويتم إخفاء شريط التتبع ومسح بيانات الطلب تلقائياً، لتصبح الطاولة جاهزة ونظيفة للزبائن الجدد بمجرد مسحهم للـ QR.

---

### 3. 🪑 إدارة الصالة والطاولات (Tables Management)
- **مخطط مرئي للصالة:** عرض كافة الطاولات وتصنيفها حسب المناطق (داخلي، خارجي، روف، VIP).
- **حالات الطاولات اللحظية:** ألوان توضيحية فورية (فاضية، مشغولة، عليها شيك، محجوزة).
- **إجراءات مرنة:** فتح طاولات، نقل طلب من طاولة لأخرى، ودمج الطاولات بضغطة واحدة.

---

### 4. 📦 المخازن والمواد الخام وتكاليف الوصفات (Inventory & Recipes)
- **إدارة المواد الخام (Raw Materials):** تتبع كميات البن، الحليب، السيرب، الصوصات، الأكواب، والمستلزمات.
- **الوصفات والمكونات (Recipes / BOM):** ربط كل مشروب أو وجبة بمكوناتها الخام ليتم خصمها تلقائياً وبدقة من المخزون مع كل فاتورة مباعة.
- **تنبيهات النواقص والحد الأدنى:** إشعارات فورية عند اقتراب أي مادة خام من النفاد.
- **حركات المخازن والمشتريات:** تسجيل فواتير المشتريات، الموردين، مرتجعات المشتريات، والجرد الدوري.

---

### 5. 💼 الورديات والشفتات وإدارة الخزينة (Shifts & Treasury)
- **بدء وإنهاء الوردية (Start / End Shift):** تسجيل رصيد بداية الدرج، ومطابقة النقدية الفعلية مع مبيعات النظام واكتشاف العجز أو الزيادة بدقة.
- **حركة الخزينة المتعددة:** تتبع مستقل للنقدية بالدرج، المحافظ الإلكترونية، وحسابات البنك.
- **المصروفات النثرية:** إثبات فوري لكافة المصاريف اليومية وسندات الصرف والقبض.

---

### 6. 👥 شؤون العاملين والموظفين (HR & Payroll)
- ملف تعريفي لكل موظف وتحديد وظيفته (كاشير، ويتر، باريستا، شيف، إداري).
- تسجيل المرتبات الأساسية، السلفيات، المكافآت، الخصومات، ومتابعة الحضور والانصراف.

---

### 7. 🖨️ منظومة الطباعة الحرارية (Thermal Printing)
- **دعم كامل لطابعات الفواتير:** مقاسات 80mm و 58mm عبر منافذ USB أو الشبكة (Network/LAN).
- **طباعة سطح المكتب والويب:**
  - يعمل محلياً في برنامج سطح المكتب بضغطة زر.
  - يدعم العمل عبر المتصفح (Web App) بإنشاء إطارات طباعة مخصصة.
  - يدعم وضع **Kiosk Printing** في جوجل كروم/إيدج للطباعة الصامتة والتلقائية بدون فتح نوافذ الحوار.
- **تنوع المستندات المطبوعة:** فواتير الكاشير، شيك المعاينة، تذاكر المطبخ والبار، وإيصالات الدليفري.

---

### 8. 💬 تكامل الواتساب (WhatsApp Integration)
- إرسال تفاصيل الفاتورة والإيصال للعميل مباشرة على هاتفه عبر الواتساب بنقرة واحدة.
- إرسال تقرير تقفيل الوردية اليومي وملخص الإيرادات تلقائياً لرقم إدارة الكافيه.

## 🚀 التثبيت والتشغيل في بيئة التطوير

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (يوصى بالإصدار 18 أو 20 LTS).
- أدوات البناء لبيئة ويندوز (`windows-build-tools` أو Visual Studio Build Tools).

### خطوات التشغيل
1. **تثبيت التبعيات البرمجية:**
   ```bash
   npm install
   ```

2. **تجهيز وإعادة بناء الإضافات الأصلية لـ Electron:**
   ```bash
   npm run postinstall
   ```

3. **تشغيل البرنامج:**
   ```bash
   npm start
   ```

## 🔒 الصلاحيات والأمان

- **حساب المدير (Admin):** صلاحيات كاملة تشمل الإعدادات، الأسعار، تقارير الأرباح، الرواتب، وإلغاء أو تعديل الفواتير.
- **حساب الكاشير (Cashier):** صلاحيات محددة لفتح الفواتير، اختيار الترابيزات، وتحصيل المبالغ دون الاطلاع على أرباح النظام أو تعديل الإعدادات الحساسة.
- **النسخ الاحتياطي التلقائي:** نسخ احتياطي فوري لقاعدة البيانات محلياً لحماية بيانات المبيعات والمخازن.
